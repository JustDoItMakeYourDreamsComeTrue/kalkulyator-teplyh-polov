# Калькулятор тёплого пола

Статическая страница без сборки. Её можно открыть файлом `index.html` или выложить на GitHub Pages как есть.

Подбор электрического пола **WÄRMEHAUS** и **Grand Meyer**: мат, тонкий кабель, кабель в стяжку или плёнка. На выходе — конкретные секции, шаг укладки, схема сверху, пирог пола, ток, автомат и ответ, хватит ли мощности как единственного отопления.

## Как посчитать

1. Откройте `index.html`.
2. Возьмите готовый пример или впишите свою комнату.
3. Мебель без ножек вычитается из площади. Диван на ножках не вычитают.
4. Необязательные поля (утепление, что под полом, окна) уточняют, потянет ли пол комнату в мороз. На выбор мата для тёплой плитки они почти не влияют.

Кнопки «Ванная», «Гостиная» и «Кухня» подставляют контрольные комнаты.

## GitHub Pages

1. Создайте репозиторий и залейте в него содержимое этой папки, чтобы `index.html` лежал в корне.
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://<user>.github.io/<repo>/`.

Отдельная сборка не нужна. Файл `.nojekyll` уже лежит в корне, чтобы Pages не прятал служебные файлы.

## Откуда цифры

- Секции WÄRMEHAUS MAT 160, MAT 200, CAB 17W, CAB 20W и плёнки EcoPower / SelfReg / High Power — по открытым картам производителя и поставщиков. У CAB 17W в карточках мощность секции часто ниже, чем «17 Вт × длина»; калькулятор берёт ватты с карточки.
- Grand Meyer THC20, THM200, EcoNG150, EcoNG170 и регуляторы MST-1, HW-500, W350 — по каталогу Grand Meyer. Шаг THC20 считается как `100 × S / L` и сверяется с рядом 7,5–17,5 см.
- Поток с поверхности — упрощение EN 1264: `q = 8,92 × (t_пола − t_воздуха)^1,1`. Из-за этого паспортные 200 Вт/м² не обещают 200 Вт тепла в комнату: регулятор упирается в предел покрытия.
- Теплопотери — оценочный баланс одной комнаты (одна наружная стена по умолчанию), не энергетический паспорт дома.

Перед покупкой сверьте артикул и сопротивление с паспортом конкретной бухты. Цены в калькулятор не входят: они разные по странам и быстро устаревают.
